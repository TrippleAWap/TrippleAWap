### About

I am a software engineer specializing in network protocols, reverse engineering, and game client architecture. My work centers on building high-performance MITM proxies, low-level packet manipulation tools, and custom protocol implementations from scratch. I actively build infrastructure for platforms including Minecraft Bedrock, VRChat, and Xbox Live, often operating at the ABI and raw socket levels.

### Core Proficiencies

Rather than maintaining a static list of projects, my engineering efforts are focused on the following domains:

**Protocol Engineering & Reverse Engineering**
- Custom protocol implementations from scratch (Rust, C++, Go).
- Low-level packet manipulation, disassembly analysis, and native structure mapping.
- Runtime interpreters and protocol definition systems.

**Networking & Security**
- MITM proxies for packet filtering and exploit mitigation.
- Packet parsing to intercept malformed data before it hits the server.
- Anti-cheat systems and traffic manipulation.

**Game Clients & Virtual Reality**
- Custom game clients and memory-injected modifications.
- Cache scraping, asset extraction, and REST API exploitation for VR platforms.
- Cross-platform client implementations (Windows, Android).

**Platform Integrations & Auth Flows**
- Custom authentication flows and token caching for Xbox Live and Azure PlayFab.
- RESTful API wrappers (TypeScript, Go) for proprietary services.
